# Gold Research | 黄金投资研究

研究主题：黄金价格驱动机制的历史演变及未来3—12个月投资展望。

研究基准日：2026年11月10日。

当前状态：已获准完成首轮黄金与实际利率事实整理；初步图表与统计已交付，黄金日期标签待核验，尚未开展宏观归因。

## 项目目标

通过系统梳理历史金价、宏观数据与重大事件，理解黄金在不同市场环境下的定价逻辑，形成具有证据支持、可持续更新的专业投资研究报告。

研究先从历史事实出发，再检验经济解释；不预设黄金定价机制已经发生结构性变化，也不以建立复杂预测模型为起点。

## 核心研究问题

1. 黄金价格受到哪些重要因素驱动，各因素通过什么机制发挥作用？
2. 历史重要上涨、下跌和震荡行情中，哪些因素可能占据主导地位？
3. 相同因素为何在不同历史时期表现出不同影响？
4. 黄金的主要定价机制是否随市场环境变化？
5. 当前环境与历史阶段有何异同，对未来3个月、6个月和12个月有何启示？

## 研究路线

1. **驱动因素研究**：明确候选因素的理论机制、适用条件和历史反例。
2. **历史行情整理**：收集长期金价，识别主要行情阶段与关键转折点。
3. **历史归因研究**：结合宏观数据、政策、地缘政治、市场预期及资金行为，核验支持证据与竞争性解释。
4. **跨周期比较**：比较不同阶段的主导因素及关系稳定性，检验可能的机制变化。
5. **当前环境与情景展望**：以基准日前可获得的信息建立未来3—12个月多空情景，记录触发条件与失效条件。

相关性分析、事件研究、结构变化检验及模型实现按研究需要开展，可服务于上述阶段；不把复杂模型视为必经终点。每次任务范围及阶段转换由项目负责人确认。

## 协作分工

本项目采用**研究决策与技术执行分离的阶段式协作**，以完整技术任务为授权和交付单位。

| 角色 | 主要职责 |
| --- | --- |
| 项目负责人 | 决定研究方向、优先级、关键研究口径及阶段验收，批准阶段转换 |
| ChatGPT | 研究问题、理论框架、研究假说、历史事件研究、经济解释和报告撰写 |
| Codex | 自主完成授权范围内完整的技术任务，包括数据获取、清洗、计算、可视化、验证与技术问题处理，维护可复现成果 |

基本流程：**确定研究问题与关键口径 → 负责人批准完整技术任务 → Codex自主执行与验证 → 阶段成果包交接 → ChatGPT开展已授权的研究分析与报告撰写 → 负责人阶段验收并决定下一步**。

授权任务内，Codex自行完成必要的数据获取、清洗、异常排查、代码修复、统计计算、图表调整和验证，不因普通技术问题频繁暂停，也不为每个子步骤请求批准。技术执行不能自行扩大研究范围或进入未授权的新阶段。

需要改变已确定的核心来源或研究口径、存在影响结论且证据不足以取舍的处理方案、数据质量在合理调查后仍无法解决、证据不足以支撑关键结论，或需要改变研究目标、假说及阶段时，Codex向负责人提交明确决策请求，说明问题、已验证事实、可选方案、优缺点和建议。

完整技术任务结束后交付精简成果包，默认入口为 `outputs/review/summary.md`，链接必要图表、关键统计结果、数据质量与局限性说明及复现证据；有待决事项时提供 `outputs/review/decisions_required.md`。没有内容的项目不建空文件，多项任务保留各自版本。所有研究结果应追溯到原始数据、处理代码和运行记录；详细规则见 [AGENTS.md](AGENTS.md)。

## 研究原则

- 优先使用可追溯的原始数据和同期资料，注明来源、统计口径与处理方法。
- 区分历史观察、统计结果、经济解释及待验证假说。
- 不伪造数据或事件，不将相关性或同期发生直接解释为因果关系。
- 不通过优化相关性倒推数据日期，不为得到预设结论修改处理规则；未经批准，Codex不自行作出正式宏观归因或投资预测。
- 记录数据发布日期与修订情况，避免使用当时尚不可知的信息。
- 对证据不足、无法解释的行情和竞争性解释保留不确定性。
- 不擅自修改既有研究结论；提出修订时保留原判断、变更理由及证据。
- 每次交付说明结果、验证情况、限制和待解决问题，完成后等待下一项任务。
